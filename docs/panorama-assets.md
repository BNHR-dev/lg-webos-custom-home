# Panorama resource provenance

- `developer_home/assets/panorama.svg` and `dunes.svg`: original geometric landscapes
  created for this fork, distributed under the repository MIT licence. No stock photo,
  generated paid image, proprietary font or external font request is included.
- Existing application icons `icon.png` / `largeIcon.png` retain their existing provenance.
- Final private installation: the same local YouTube, Twitch, Netflix and Crunchyroll
  SVGs as the approved design, from Simple Icons 16.36.0. Their declared upstream
  sources are YouTube brand resources, Twitch brand resources, Netflix brand assets
  and crunchyroll.com. The collection's CC0 declaration does not establish brand
  redistribution permission. They remain local only, with no third-party app code.
- An initial attempt used icons from installed packages. Those were rejected visually
  by the user and are no longer referenced by the entertainment shortcuts.
- The private 0.2.2 installation uses the official Disney+ SVG monogram from
  [Disney's static assets](https://static-assets.bamgrid.com/product/disneyplus/favicons/mask-icon-aurora.86b2f302cf50180b25ddd8835041b1c3.svg),
  prepared white; the official transparent Prime Video wordmark from
  [Amazon's assets](https://m.media-amazon.com/images/G/01/digital/video/web/logo-min-remaster.png);
  and the [CANAL+ SVG](https://thumb.canalplus.pro/static/canalplus-logo-v2.svg)
  linked by its [media kit](https://www.canalplus.com/presse/kit-media), prepared
  white with transparent letter counters. Official origin alone does not grant
  redistribution rights: none of these files is included in this repository.
- `developer_home/assets/wind.svg` is an original MIT-licensed wind composition
  used locally for Breezyfin. It is not an official Breezyfin logo. No code or
  artwork from that project's GPL repository was copied.
- Full wordmarks can suppress redundant captions with `logoContainsName: true`;
  monograms and the generic wind composition retain readable captions.
- The generic package needs no branded assets: missing images fall back to text.
  Add icons only when you have the required permission and record their provenance.
